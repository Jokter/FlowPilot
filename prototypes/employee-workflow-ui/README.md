# 一次性员工流程工作台原型

这个原型只用于比较页面信息架构，不是产品代码。

## 评审结论

- 选择日期：2026-08-17
- 选择方案：A，引导式三栏工作台
- 选择原因：同时呈现流程进度、Codex 多轮协作、完成条件与交付证据，适合不熟悉团队流程的新员工。
- 后续设计：以 A 为基础，吸收 C 中清晰解释“当前步骤要做什么”的引导文案。

在项目根目录运行：

```powershell
node prototypes/employee-workflow-ui/server.mjs
```

打开 `http://127.0.0.1:4173/?variant=A`，使用页面底部按钮或键盘左右方向键切换：

- A：引导式三栏工作台
- B：Codex 对话驾驶舱
- C：新员工清单向导
